Fontes e recolha

Canais e vídeos do YouTube, feeds RSS e sítios web públicos de onde o sistema recolhe publicações novas.

{% endif %}

Nova fonte

Feed RSS: endereço do feed. Sítio: página inicial ou de secção (o sistema segue as ligações para artigos do mesmo sítio). Canal: @nome ou identificador UC…

Regras da recolha

  • Só conteúdo público. Páginas que pedem autenticação são ignoradas, nunca contornadas.
  • O sistema respeita o robots.txt de cada sítio, identifica-se como «{{ cfg.recolha_agente[:40] }}…» e espera {{ cfg.recolha_intervalo_s|num(0) }} s entre pedidos ao mesmo sítio.
  • Das páginas web guarda o título e os primeiros parágrafos. Comentários carregados por JavaScript (por exemplo, Facebook ou Disqus) não são recolhidos.
  • YouTube: usa a API oficial e precisa de UAN_YOUTUBE_CHAVE {% if tem_youtube %}configurada{% else %}em falta{% endif %}.
  • Cada recolha fica registada como um lote, com a via (API oficial ou página pública), e os autores são anonimizados à entrada.

Para recolher de forma periódica, agende python uan.py recolher no Agendador de Tarefas do Windows.
